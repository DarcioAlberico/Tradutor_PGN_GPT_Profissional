# Curadoria de trocas repetidas

**Roadmap:** RG-022. Permitir criar uma sugestão de glossário a partir de uma
troca repetida, com escopo do par de idiomas, usando o catálogo transacional.
A ação nunca altera traduções; conflitos de revisão e duplicatas não gravam.
Validar criação, ausência de destino, conflito concorrente e interface.
